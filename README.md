# Weather App ☁️

A simple weather application built using HTML, CSS, and JavaScript.

## Features
- Search weather by city name
- Displays:
  - Temperature
  - Weather condition
  - Wind speed
  - Humidity
- Responsive and clean UI

## Technologies Used
- HTML
- CSS
- JavaScript
- OpenWeather API

## Project Purpose
This is a beginner-friendly frontend project created for practicing API integration and DOM manipulation using JavaScript.

## How to Run
1. Download or clone the repository
2. Open `index.html` in your browser
